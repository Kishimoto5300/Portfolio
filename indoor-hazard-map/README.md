# 室内危険箇所 3Dマップ

高齢者の家庭内事故を防ぐための 3D チェックツールです。
間取り図の画像から壁を立体化し、家具を置き、つまずき・段差などの危険箇所にピンを立てて、室内の危険を立体的に確認できます。

**デモ：** https://kishimoto5300.github.io/Portfolio/indoor-hazard-map/

## できること

1. **間取り図を 3D 化**：PNG / JPEG の間取り図をアップロードすると、線を検出して壁を立てます。文字は自動で除去し、壁の高さ・検出感度・壁とみなす最小の長さを調整できます。
2. **家具・ドアの配置**：ベッド、ソファ、テーブル、椅子、棚、テレビ、冷蔵庫、トイレ、ドアを床に置き、ドラッグで移動、サイズ変更・回転ができます。
3. **危険箇所の登録**：床・壁・家具をクリックして、危険の種類（段差・階段／滑りやすい／つまずき／手すり不足／暗がり／その他）とメモを登録します。
4. **一人称視点**：部屋の中を歩いて見回し、その場から危険箇所や家具を追加できます。
5. **保存・書き出し**：間取り・壁・家具・危険箇所を 1 つの JSON ファイルに保存して復元できます。3D モデル（.glb）としても書き出せます。

## 制作中の機能

- **安全チェック**：家具どうしの間の通行幅や、ベッドからトイレまでの経路を、通常歩行 80 cm・歩行器 100 cm・車椅子 120 cm の基準で確認する機能です（3D 上の 1.0 単位 = 1 m とした目安で、実寸の校正前の値です）。判定がまだ完全ではないため、公開版では画面から外しています。

## 使い方

1. デモを開き、「① 見取り図をアップロード」に間取り図の画像をドロップします。試すときは [`samples/`](samples/) のサンプル間取り図を使えます。
2. 読み込むと自動で壁が立ちます。うまく立たないときは、壁の検出感度や壁とみなす最小の長さを調整します。
3. 家具を置き、「⚠️ 危険箇所を追加」で危険箇所を登録します。

データはブラウザの中だけで処理され、どこにも送信されません。

## 構成

- `index.html`：アプリ本体です。ライブラリ（three.js、Tailwind CSS など）を埋め込んだ 1 つの HTML ファイルなので、インターネットにつながっていなくても動きます。
- `samples/`：動作確認用のサンプル間取り図（1LDK など）です。
