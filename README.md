概要

本リポジトリでは、Pythonを用いたデータ分析、機械学習、コンピュータビジョンに関する課題および個人開発の成果物を公開しています。

講義や自主学習を通じて、ライブラリを利用するだけでなく、アルゴリズムの理論的背景を理解した上でスクラッチ実装に取り組みました。

学んだこと

Pandas、NumPy、SciPyを用いたデータ分析に加え、機械学習アルゴリズムの理論的理解と実装を経験しました。

特に講義では、既存の機械学習ライブラリに依存せず、回帰モデルやクラス分類、主成分分析などをスクラッチで実装し、アルゴリズムの内部動作への理解を深めました。

また、コンピュータビジョン分野ではホモグラフィーの実装を通じて画像処理の基礎を学び、個人開発ではAzure Computer Visionを用いた画像認識システムの実装に取り組みました。
