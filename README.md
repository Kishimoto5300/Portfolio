# 献立ジェネレーター

予算・カロリー・調理時間の条件を入力すると、主食・主菜・副菜を組み合わせた献立を 3 案ランダムに提案する Web アプリです。

**デモ：** https://kishimoto5300.github.io/meal-generator/

## できること

- **献立の生成**：「献立を生成する」を押すと、主食・主菜・副菜の組み合わせを 3 案つくります。
- **条件での絞り込み**：合計の費用・カロリー・調理時間が、入力した予算・カロリー・調理時間以下になる組み合わせだけを提案します。
- **合計の表示**：各案の合計費用・カロリー・調理時間を表示します。
- **再生成**：「もう一度候補を作成」で別の組み合わせを出せます。

「好きな味」の選択欄は画面上にありますが、現時点では献立の絞り込みには反映していません。

## 技術

React 18 + TypeScript + Vite

```
src/
├── App.tsx        画面と献立の生成ロジック
├── data/meals.ts  料理データ（費用・カロリー・調理時間）
├── types.ts       型定義
└── styles.css     スタイル
spec/              生成 AI に渡した仕様書とワイヤーフレーム
```

## 開発について

生成 AI 開発ハンズオンで、仕様書（`spec/`）とワイヤーフレームをもとに AI コーディングエージェント（Codex）へ指示を出して作成しました。
`spec/` には、段階的に機能を追加したときの指示（予算での絞り込み → カロリー・調理時間での絞り込み）を残しています。

## ローカルで動かす

```bash
npm install
npm run dev
```

## 公開（GitHub Pages）

`npm run build` を実行すると `docs/` にビルド結果が出力されます。
GitHub Pages は main ブランチの `/docs` フォルダから公開しています。
