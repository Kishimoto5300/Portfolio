# ToDo アプリ（就活・学業・プライベート）

「就活」「学業」「プライベート」という状況ごとのタスクと、それらをまとめて見る「全体」の視点を、ワンタップで切り替えられるシンプルな ToDo アプリです。

**デモ：** https://kishimoto5300.github.io/Portfolio/todo-app/docs/

## なぜ作ったか

市販の ToDo アプリは多機能すぎて画面が煩雑になり、使い続けるハードルが高いと感じていました。
そこで、自分が普段の生活で本当に使いたい機能だけに絞り、最小限の操作で完結することを目指しました。

## できること

- **状況の切り替え**：「全体／就活／学業／プライベート」のタブで表示を切り替えます。「全体」はカテゴリではなく、3 つをまとめて見るための視点として扱っています。
- **タスクの追加**：タイトルに加えて、期限、形式（オンライン／対面）、メモ（移動手段など）を付けられます。
- **並び替え**：「追加した順」と「期限が近い順」を切り替えられます。
- **期限の強調**：期限切れと、期限が 3 日以内に迫ったタスクを見分けられるように表示します。
- **完了・編集・削除**：チェックで完了にし、あとから内容を編集できます。
- **自動保存**：タスクはブラウザ（localStorage）に保存され、ページを閉じても残ります。サーバーには送信されません。

## 技術

React 19 + Vite（JavaScript）

```
src/
├── App.jsx         画面とタスク操作
├── TaskFields.jsx  入力欄（期限・形式・メモ）
├── taskLogic.js    絞り込み・並び替え・期限判定などのロジック
├── constants.js    タブ・並び順・形式などの定義
└── storage.js      localStorage への保存と読み込み
```

## 開発の進め方

就職活動の面談課題として、生成 AI を「思考整理パートナー」に見立てて開発しました。
コードを一括生成させず、次の順で 1 ステップずつ合意を取りながら進めました。

1. コンセプトと「なぜ必要か」の言語化
2. データ構造と状況切り替えの設計
3. シンプルさを崩さない画面構成の検討
4. Vite 環境での段階的な実装
5. 振り返りとリファクタリング

## ローカルで動かす

```bash
npm install
npm run dev
```

## 公開（GitHub Pages）

`npm run build` を実行すると `docs/` にビルド結果が出力されます。
`docs/` は Portfolio リポジトリの GitHub Pages から `todo-app/docs/` として公開されます。
